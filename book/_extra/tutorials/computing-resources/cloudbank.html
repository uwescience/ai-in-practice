Why cloud?

The work you're doing this week may benefit from cloud computing tools! With cloud you can:

  • Move compute to large training datasets — no more downloading terabytes to a laptop

  • Temporarily deploy GPU instances for intensive training tasks

  • Run multiple parallel fine-tuning runs or reinforcement learning experiments simultaneously

  • Share reproducible environments so that collaborators can work in the same setup

  • Host collaborative infrastructure such as API gateways and live model endpoints

What CloudBank is

NSF's managed gateway to commercial cloud for research

Since 2019

NSF-funded cloud access entity, co-led by UC San Diego (SDSC), UC Berkeley, and UW eScience

Five cloud providers

Managed access to AWS, Google Cloud, IBM Cloud, Microsoft Azure, and NVIDIA DGX Cloud, plus onboarding, training, billing support, and a shared portal

CloudBank 2.0

$20M NSF award in 2025 — five-year horizon, ~500 projects/year, expanded eligibility to any U.S. researcher or educator at academic, non-profit research, or educational institutions

NAIRR interface

CloudBank is the interface for private-sector cloud contributions to the National AI Research Resource (NAIRR) Pilot

Getting access

Access cloud resources through CloudBank — two funding routes

CloudBank Portal

Same onboarding, support team, and billing help.

NAIRR Pilot

AI research, or research that uses AI

  • Free cloud credits on AWS, Azure, and Google Cloud
  • Pre-trained models, AI-ready datasets, and sandboxes
  • 12-month projects · results must be open and publishable

How Much Funding Is Available?

Tier Range Best for
Explore up to $10K Pilots, first-time users, coursework
Discover $10K–$37.5K Modest projects, gateway development
Accelerate $37.5K–$75K Larger programs, 3-page justification
Maximize Semi-annual review Large-scale, longer-horizon projects
  • Credits are issued in two halves. The second arrives after you submit a progress report.
  • Explore and Discover are good entry points — larger tiers are available as projects mature.
  • NAIRR allocations are direct resource awards, not credits, and can be much larger for AI work. Grand-challenge Azure partnerships reach up to $3.5M.

From UW Earth & Space Sciences

Example: Automated earthquake detection at cloud scale

The project

Marine Denolle and other researchers built a cloud pipeline for automated earthquake detection, combining template matching and PhaseNet, a deep neural network for seismic phase picking

The cloud pattern

Azure Container Instances for compute · Azure Files for data · Azure Batch to parallelize across a VM pool — one day of data per VM, overnight

Why cloud was necessary

On-demand access to machines that "exceed the capabilities of our lab servers, which can get crowded at times"

Connection to this week

Container Instances + Batch is the same cloud-agnostic pattern the SkyPilot tutorial will teach.
